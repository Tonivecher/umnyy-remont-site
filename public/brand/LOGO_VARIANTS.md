# Логотип «Умный Ремонт»

Выбранный вариант: монограмма «УР» из предоставленного референса.

## Файлы

- `logo-current.svg` — горизонтальный логотип для сайта.
- `logo-current-icon.svg` — квадратная иконка для hero, Telegram, favicon и mini app.
- `logo-current-mark.svg` — прозрачная монограмма без подложки для специальных носителей.
- `telegram-avatar.svg` / `telegram-avatar.png` — версия для аватаров канала и бота.

## Цвета

- Графитовая подложка: `#070707`
- Основное золото: `#d6b36a`
- Тёмное золото для глубины: `#9e7b36`
- Тёплый белый текст: `#f5f1e8`

Золото сделано немного светлее исходного референса, чтобы знак не сливался с тёмным интерфейсом сайта и Telegram Mini App.
